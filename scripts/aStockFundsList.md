## API使用说明

### 获取基金实时数据

```javascript
// API地址格式
const url = `http://fundgz.1234567.com.cn/js/${fundCode}.js`;

// 返回数据格式（JSONP）
jsonpgz({
  "fundcode": "001770",      // 基金代码
  "name": "前海开源嘉鑫灵活配置混合C",  // 基金名称
  "jzrq": "2026-01-03",      // 净值日期
  "dwjz": "2.4820",          // 当日净值
  "gsz": "2.4797",           // 估算净值
  "gszzl": "-0.09",          // 估算涨跌幅(%)
  "gztime": "2026-01-06 15:00"  // 估值时间
});
```

### 数据字段说明

- `fundcode`: 基金代码
- `name`: 基金名称
- `jzrq`: 净值日期（上一个交易日）
- `dwjz`: 当日净值（上一个交易日的实际净值）
- `gsz`: 估算净值（当前交易日的估算净值）
- `gszzl`: 估算涨跌幅（相对于上一个交易日的涨跌幅，单位：%）
- `gztime`: 估值时间（数据更新时间）

### 计算当日收益

```javascript
// 当日收益率 = gszzl (估算涨跌幅)
const dailyReturn = parseFloat(data.gszzl);

// 当日收益金额 = 持仓金额 × (当日收益率 / 100)
const dailyProfit = investmentAmount * (dailyReturn / 100);
```

## 使用建议

1. **交易时间**：工作日 9:30-15:00，数据实时更新
2. **非交易时间**：显示上一个交易日的数据
3. **更新频率**：交易时间内约每分钟更新一次
4. **数据延迟**：估算数据有约15分钟延迟
5. **请求限制**：建议每个基金间隔至少500ms，避免请求过快
