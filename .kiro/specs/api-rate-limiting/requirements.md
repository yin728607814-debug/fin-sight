# API 速率限制优化需求文档

## 简介

当前应用在使用 Gemini API 进行新闻分析时频繁遇到 429 错误（请求过于频繁）。需要实现一个智能的速率限制和请求队列系统，以确保应用在 API 限制内正常运行。

## 术语表

- **Gemini API**: Google 的生成式 AI API 服务
- **速率限制 (Rate Limiting)**: API 提供商对请求频率的限制
- **请求队列 (Request Queue)**: 管理和调度 API 请求的队列系统
- **令牌桶算法 (Token Bucket)**: 一种流量控制算法
- **批量处理 (Batch Processing)**: 将多个请求合并处理

## 需求

### 需求 1: 实现请求队列系统

**用户故事:** 作为系统管理员，我希望应用能够智能管理 API 请求，以避免超出速率限制。

#### 验收标准

1. WHEN 多个新闻分析请求同时到达 THEN 系统应将它们加入队列并按顺序处理
2. WHEN 队列中有待处理请求 THEN 系统应根据速率限制自动调度请求
3. WHEN API 返回 429 错误 THEN 系统应自动延迟后续请求
4. WHEN 请求在队列中等待超过 30 秒 THEN 系统应回退到本地分析
5. WHERE 队列已满 THEN 系统应拒绝新请求并返回本地分析结果

### 需求 2: 实现令牌桶速率限制器

**用户故事:** 作为开发者，我希望使用令牌桶算法来精确控制 API 请求速率。

#### 验收标准

1. WHEN 系统初始化 THEN 令牌桶应填充初始令牌数（15个）
2. WHEN 发起 API 请求 THEN 系统应消耗一个令牌
3. WHEN 令牌桶为空 THEN 系统应等待令牌补充
4. WHEN 时间流逝 THEN 系统应按固定速率（每 4 秒 1 个）补充令牌
5. WHERE 令牌桶已满 THEN 系统应停止补充令牌

### 需求 3: 实现批量分析优化

**用户故事:** 作为用户，我希望应用能够智能地批量处理新闻分析，减少 API 调用次数。

#### 验收标准

1. WHEN 短时间内有多条相似新闻 THEN 系统应合并为一次 API 调用
2. WHEN 批量分析完成 THEN 系统应将结果分发给各个请求
3. WHEN 批量大小超过 5 条新闻 THEN 系统应拆分为多个批次
4. WHEN 批量等待超过 2 秒 THEN 系统应立即处理当前批次
5. WHERE 新闻内容相似度超过 80% THEN 系统应复用分析结果

### 需求 4: 增强缓存策略

**用户故事:** 作为用户，我希望应用能够更智能地缓存分析结果，减少重复的 API 调用。

#### 验收标准

1. WHEN 分析相同新闻内容 THEN 系统应返回缓存结果
2. WHEN 缓存命中 THEN 系统应记录缓存统计信息
3. WHEN 缓存过期（30分钟后）THEN 系统应自动清理
4. WHEN 内存使用超过阈值 THEN 系统应清理最旧的缓存项
5. WHERE 缓存大小超过 100 项 THEN 系统应使用 LRU 策略淘汰

### 需求 5: 实现降级策略

**用户故事:** 作为用户，即使 API 不可用，我也希望能够获得基本的分析结果。

#### 验收标准

1. WHEN API 连续失败 3 次 THEN 系统应切换到本地分析模式
2. WHEN 处于降级模式 THEN 系统应每 5 分钟尝试恢复 API 调用
3. WHEN API 恢复正常 THEN 系统应自动切换回 AI 分析模式
4. WHEN 降级发生 THEN 系统应通知用户当前使用本地分析
5. WHERE 本地分析也失败 THEN 系统应返回默认的中性分析结果

### 需求 6: 添加监控和指标

**用户故事:** 作为开发者，我希望能够监控 API 使用情况和性能指标。

#### 验收标准

1. WHEN API 请求完成 THEN 系统应记录响应时间
2. WHEN 发生速率限制 THEN 系统应记录限制次数
3. WHEN 缓存命中 THEN 系统应更新命中率统计
4. WHEN 请求失败 THEN 系统应记录失败原因和次数
5. WHERE 开发模式 THEN 系统应在控制台输出详细指标

### 需求 7: 配置管理

**用户故事:** 作为系统管理员，我希望能够灵活配置速率限制参数。

#### 验收标准

1. WHEN 系统启动 THEN 应从配置文件读取速率限制参数
2. WHEN 配置更新 THEN 系统应动态调整速率限制器
3. WHEN 使用免费 API THEN 系统应使用保守的限制（12次/分钟）
4. WHEN 使用付费 API THEN 系统应使用更高的限制（60次/分钟）
5. WHERE 环境变量存在 THEN 系统应优先使用环境变量配置
